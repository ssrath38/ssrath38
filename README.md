## 💻 Featured Projects

### 🌾 SASYA - Rice Yield Estimation App
* **Description:** A comprehensive desktop application designed to estimate rice crop yields. Instead of traditional machine learning, this app utilizes complex **semi-physical crop modeling** to automate the agricultural data pipeline and generate accurate environmental forecasts.
* **Tech Stack:** Python, PySide6, Semi-Physical Modeling

### 🌍 Odisha Climate Explorer
* **Description:** A full-stack spatial data exploration tool built to visualize and analyze historical and predictive climate data for the Odisha region. It provides seamless interaction with climate datasets to monitor temperature trends and rainfall patterns.
* **Tech Stack:** FastAPI (Backend), React (Frontend), Python, Spatial Data Processing
